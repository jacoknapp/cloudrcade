Select a GameCube ISO or GCM. Menu pauses the game and opens CloudRcade's standard menu for save states and exit. The side panel controls the touch layout and mute.

Requires browser WebGPU on the device GPU. Games over50MB stream using the existing2MiB disk chunks and16MiB cache.

Keyboard: X/Z/V/B = A/B/X/Y; Q/E/C = L/R/Z; Enter = Start; arrows = D-pad; WASD = stick; IJKL = C-stick; Escape = pause menu. Standard gamepads and existing touch controls are supported.
