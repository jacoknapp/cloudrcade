Experimental GameCube

Back to library

Select a GameCube ISO or GCM. Game controls, sound, saves and exit use CloudRcade's pop-out menu.

Requires browser WebGPU on the device GPU. Games over50MB stream using the existing2MiB disk chunks and16MiB cache.

Keyboard: X/Z/V/B = A/B/X/Y; Q/E/C = L/R/Z; Enter = Start; arrows = D-pad; WASD = stick; IJKL = C-stick; Escape = pop-out menu. Standard gamepads and existing touch controls are supported.
