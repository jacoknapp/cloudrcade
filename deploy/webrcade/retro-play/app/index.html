PlayStation 2 (experimental)

Select an ISO, CHD or homebrew ELF. Games run on your device using Play! and device WebGPU. No external BIOS is needed.

Menu opens CloudRcade's save slots and exit controls. Large discs stream with a 16 MiB cache and need a connection during play.

Keyboard: Z/X/A/S = ✕/○/□/△; arrows = D-pad; Enter/Backspace = Start/Select; 1/2/3 and 8/9/0 = L1/L2/L3 and R1/R2/R3; F/H/T/G and J/L/I/K = sticks; Escape = Menu.

PS2 compatibility and speed vary by game and device.
